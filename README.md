# AILIN TEA PRACTICE — сайт (статический)

Готовый одностраничный сайт. Ничего собирать не нужно — это чистые HTML/CSS/JS.

## Состав
```
site/
├── index.html      — страница (все секции)
├── styles.css      — стили (дизайн-система)
├── i18n.js         — словарь строк (RU) + applyI18n() для будущей EN-версии
├── script.js       — меню, анимации, lightbox, форма, копирование WeChat ID
├── media/          — фото и видео (сжатые)
└── assets/         — логотип (SVG), favicon, OG-картинка, обложки видео, icons/ (Telegram, VK, Instagram, WeChat)
```

## Как посмотреть локально
- Просто открыть `index.html` в браузере, **или**
- запустить локальный сервер (лучше — так корректно грузятся шрифты/видео):
  ```bash
  cd site && python3 -m http.server 8080
  # открыть http://localhost:8080
  ```

## Как опубликовать (выбрать одно)
1. **Netlify (проще всего, бесплатно):** зайти на app.netlify.com → «Add new site» → «Deploy manually» → перетащить папку `site/`. Готово, выдаст ссылку `*.netlify.app`. Свой домен привязывается в настройках.
2. **Vercel:** vercel.com → New Project → загрузить папку (или через `vercel` CLI). 
3. **GitHub Pages:** залить содержимое `site/` в репозиторий, включить Pages.
4. **Обычный хостинг:** загрузить содержимое `site/` в корень (public_html) по FTP.

## Правки
- Тексты — в `index.html` (русская версия остаётся в разметке, важно для SEO).
- Цвета/типографика — переменные в начале `styles.css` (`:root`).
- Логотип — `assets/logo_ailin_seal.svg` (тёмный) и `..._light.svg` (для тёмного фона), плюс инлайн-копия в шапке/подвале `index.html`. В шапке у SVG обрезан `viewBox` по краям знака (`40 50 556 140`), размер задаёт `.header-logo` в `styles.css`.
- Словарь `i18n.js` не править руками: он пересобирается из `index.html` (русский текст живёт в разметке).
- Контакты/ссылки Telegram — искать `t.me/a_linshar`. Иконка Telegram появляется у любой ссылки на `https://t.me/` сама (правило в `styles.css`), добавлять её руками не нужно.
- Иконки соцсетей у других ссылок — класс `si` плюс `si-inst`, `si-vk`, `si-wc` или `si-tg`.

## Английская версия (i18n)
Сайт подготовлен к переводу без переписывания разметки:
- каждый видимый текст помечен `data-i18n="ключ"` (у полей формы — `data-i18n-ph`);
- полный словарь строк вынесен в `i18n.js` (объект `I18N.ru` заполнен; `I18N.en` — заготовка).

Чтобы включить EN:
1. Заполнить `I18N.en` теми же ключами, что и в `I18N.ru`.
2. Вызвать `applyI18n('en')` — например, из кнопки-переключателя языка. Непереведённые
   ключи автоматически откатываются на русский, так что переводить можно постепенно.
